# ربات پویا فلایت — نسخه حرفه‌ای ۲

## قابلیت‌ها

- ثبت‌نام مرحله‌ای و اعتبارسنجی اطلاعات
- کد رهگیری و پیگیری وضعیت
- دریافت قرارداد امضاشده
- پنل مدیریت با دستور `/admin`
- آمار ثبت‌نام‌ها
- جست‌وجو با نام، شماره، کد ملی یا کد رهگیری
- مشاهده پرونده هنرجو
- تغییر وضعیت و اطلاع‌رسانی خودکار به هنرجو
- یادداشت داخلی مدیر
- خروجی Excel
- پیام همگانی
- مهاجرت خودکار دیتابیس قدیمی

## راه‌اندازی Railway

1. فایل‌ها را در GitHub قرار دهید.
2. در Railway متغیرهای زیر را بسازید:

```text
BOT_TOKEN=توکن ربات
ADMIN_ID=5679516922
DATA_DIR=/data
```

3. یک Volume روی مسیر `/data` متصل کنید.
4. فایل قرارداد را با نام دقیق `Contract.pdf` در پوشه `contracts` قرار دهید.
5. Redeploy کنید.

## پنل مدیریت

در تلگرام دستور زیر را بفرستید:

```text
/admin
```

## اجرای محلی

```bash
pip install -r requirements.txt
python bot.py
```

## تست ساختار

```bash
python -m compileall .
```


## بررسی رسید پرداخت توسط مدیر
پس از ارسال عکس یا PDF رسید، ربات آن را همراه مشخصات هنرجو برای تمام مدیران موجود در `ADMIN_IDS` می‌فرستد. مدیر با دکمه‌های «تأیید پرداخت» یا «رد پرداخت» نتیجه را ثبت می‌کند و هنرجو به‌صورت خودکار پیام نتیجه را دریافت می‌کند.

نمونه تنظیم مدیران در Railway:
```env
ADMIN_IDS=5679516922
```
برای چند مدیر، شناسه‌ها را با ویرگول جدا کنید.
